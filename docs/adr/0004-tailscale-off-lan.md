# LAN plus Tailscale for off-LAN reach; no public proxy

Operators need to reach the Add-on’s pairing port (`3773`) from outside the home LAN without exposing it to the public internet. We support **LAN** and **Tailscale** (HA host on the mesh; desktop on the same tailnet), document Tailscale as the recommended off-LAN path, and allow one-line mention of an equivalent private mesh. Pairing URLs use existing **`advertise_host`** set to the host’s MagicDNS name (or Tailscale IP). The Add-on does **not** integrate Tailscale itself (`host_network` is enough). We reject documenting public HTTPS reverse proxy, HA Ingress, or port-forwarding `3773` as supported paths because a misconfigured public listener is a security nightmare for an unauthenticated-until-paired agent surface. Auto-detecting a Tailscale address in `run.sh` is deferred.
